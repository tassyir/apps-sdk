Its problem `type`: `https://developers.tassyir.io/errors/service-unavailable`; its `title`: Service unavailable.

## What to do

HTTP 503. Something Tassyir depends on is down. Retry with backoff, writes with the
same `Idempotency-Key`.

The answer's `fix`: Retry with exponential backoff.

## Answered by

Every operation of the Admin API, with HTTP 503.

Also the code of a refusal with HTTP 503 that carries no more specific code.

A hosted app's `ctx.props.TASSYIR` binding also answers it itself, before the call is sent ([Tassyir Hosting](/guides/tassyir-hosting#call-the-admin-api)).
