Its problem `type`: `https://developers.tassyir.io/errors/idempotency-key-reused`; its `title`: Idempotency-Key reused.

## What to do

HTTP 422. You reused an `Idempotency-Key` with another method, path, query or
body. Use a new key for a different write.

The answer's `fix`: Use a new Idempotency-Key for a different request; reuse a key only to retry the identical request.
