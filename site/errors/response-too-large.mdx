Its problem `type`: `https://developers.tassyir.io/errors/response-too-large`; its `title`: Response too large.

## What to do

HTTP 502. The API's answer was larger than a hosted app may receive (8 MiB).
Ask for less: a smaller `limit`, or `?fields=` with only the fields you read.

## Answered by

A hosted app's `ctx.props.TASSYIR` binding answers it itself, before the call reaches the Admin API, so the problem has no `requestId` and the API's reference does not list it. How the binding calls the API: [Tassyir Hosting](/guides/tassyir-hosting#call-the-admin-api).
