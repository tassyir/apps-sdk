Its problem `type`: `https://developers.tassyir.io/errors/hosted-call-refused`; its `title`: Hosted call refused.

## What to do

HTTP 401. A hosted app's call through `ctx.props.TASSYIR` was refused: its
installation is uninstalled or suspended, or no longer runs a released
version. It is also the answer during an `app/uninstalled` or
`business/redact` delivery. Make the call from the request that received
`ctx.props.TASSYIR`; if the installation is active, retry after a short wait
([Tassyir Hosting](/guides/tassyir-hosting#call-the-admin-api)).

The answer's `fix`: Call the Admin API through ctx.props.TASSYIR.fetch from the request that received it; if the installation is still active, retry after a short wait.

## Answered by

Every operation of the Admin API, with HTTP 401.
