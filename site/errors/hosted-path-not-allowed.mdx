Its problem `type`: `https://developers.tassyir.io/errors/hosted-path-not-allowed`; its `title`: Not an Admin API path.

## What to do

HTTP 400. The call was not to an Admin API path. Call `/apps/<version>/…`
with segments of letters, digits, `_` and `-` only: no other path, no `//`,
no trailing `/`, no percent-encoding and no `;`. The binding also reads
Tassyir's two public key documents, with `GET` at exactly
`/apps/webhook-keys` and `/apps/.well-known/jwks.json` (another method there
is `METHOD_NOT_ALLOWED`).

## Answered by

A hosted app's `ctx.props.TASSYIR` binding answers it itself, before the call reaches the Admin API, so the problem has no `requestId` and the API's reference does not list it. How the binding calls the API: [Tassyir Hosting](/guides/tassyir-hosting#call-the-admin-api).
